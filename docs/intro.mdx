# Introducción

**IDT App** es el sistema que gestiona y muestra el contenido de las pantallas
táctiles interactivas instaladas en los **Puntos de Información Turística (PIT)**
de la ciudad de Bogotá. Cada pantalla va montada en un **pedestal con Windows**
como sistema operativo, ejecutando la aplicación en un navegador.

El sistema es una aplicación web en **PHP** (sin framework), con **MySQL** como
base de datos y **jQuery** en el frontend. No requiere conexión a internet
estable para funcionar día a día (solo el sitio externo que se muestra en el
`iframe` del kiosco la necesita).

## Dos módulos independientes

| Módulo | Carpeta | Para quién | Qué hace |
|--------|---------|------------|----------|
| **Kiosco** | [`app/`](./kiosco/resumen-y-flujo) | El público que usa el pedestal | Slideshow de imágenes/video y, al tocar, acceso a la página web configurada para esa pantalla |
| **Administrativo** | [`admin/`](./admin/resumen) | Operadores del IDT | Subir contenido a la biblioteca, publicarlo por pantalla con fechas de inicio/fin, gestionar pantallas, usuarios y ver reportes |

Ambos módulos comparten una misma base de datos (`idt_app`) pero corren de forma
independiente — cada uno con su propia sesión, sus propios estilos y su propio
ciclo de vida.
